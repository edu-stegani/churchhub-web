# Igreja Hub — Plataforma Web White Label para Igrejas

O **Igreja Hub** é uma solução web *white label* desenvolvida para permitir que igrejas e ministérios tenham uma presença digital moderna, profissional e totalmente personalizável. A plataforma foi criada para facilitar a divulgação de eventos, projetos sociais, missões, formas de contribuição e informações institucionais, adaptando-se à identidade visual e às necessidades de cada comunidade.

---

## Sobre o Projeto

Muitas igrejas e projetos missionários enfrentam dificuldades para consolidar sua comunicação e alcançar mais pessoas na internet. O **Igreja Hub** surge como uma ferramenta acessível e flexível para centralizar as informações da igreja em um só lugar, fortalecendo o engajamento com os membros e aumentando a visibilidade das suas ações.

Sendo uma aplicação **white label**, a estrutura do site pode ser facilmente customizada com:
* As cores, logotipo e identidade da igreja.
* Imagens e banners próprios.
* Informações sobre a história, visão e valores da instituição.

---

## Funcionalidades Principais

* **Início / Institucional:** Apresentação da igreja, horários de cultos, localização e avisos gerais.
* **Projetos e Missões:** Espaço dedicado para divulgar o trabalho missionário e os campos de atuação suportados.
* **Missionários:** Apresentação dos missionários e das frentes de trabalho mantidas pela igreja.
* **Agenda e Eventos:** Divulgação de conferências, cultos especiais, acampamentos e encontros.
* **Ajude / Faça Parte (Arrecadação):** Seção transparente para meios de contribuição (Pix, transferência, doações) voltados à continuidade dos trabalhos sociais e evangelísticos.
* **Contato e Localização:** Formulário de contato e informações de fácil acesso para novos visitantes.

---

## Tecnologias Utilizadas

O projeto foi construído utilizando as principais tecnologias do desenvolvimento web front-end:

* **HTML5:** Estruturação semântica e acessível das páginas.
* **CSS3:** Estilização responsiva, moderna e de fácil customização.
* **JavaScript:** Interatividade e dinamismo nas seções do site.

## Como Executar o Projeto

Como a versão atual consiste no front-end da aplicação, a execução é simples e não exige instalação de dependências pesadas:

### Opção 1: Diretamente no navegador
1. Faça o clone ou download deste repositório.
2. Navegue até a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador padrão.

### Opção 2: Utilizando o VS Code (Recomendado)
1. Abra a pasta do projeto no **Visual Studio Code**.
2. Certifique-se de ter a extensão **Live Server** instalada.
3. Clique com o botão direito no arquivo `index.html` e selecione **"Open with Live Server"** (ou utilize o atalho no canto inferior do VS Code).
