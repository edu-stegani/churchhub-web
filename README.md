
# IgrejaHub

Plataforma web para igrejas.

## Sobre o projeto

Aplicação web desenvolvida para auxiliar igrejas na divulgação de eventos, avisos, horários de cultos e informações institucionais.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Status

Em desenvolvimento.

## Como executar

Abra o arquivo `index.html` no navegador.

## Objetivo

Projeto pessoal para praticar desenvolvimento web e evoluir uma aplicação do zero.
